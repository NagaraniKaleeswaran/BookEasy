# BookEasy 

A comprehensive appointment scheduling application built with Flutter and Laravel. 

![Branding](assets/images/icon.png)

## Overview
BookEasy is a complete SaaS solution for service-based businesses. It provides a robust Laravel-powered backend with a beautiful Admin Dashboard, paired with a pristine, modern Flutter application for customers to book appointments, manage their profile, and browse services.

## Key Features
* **Authentication:** Secure Sanctum-powered auth with persistent sessions.
* **Service Browsing:** View available services, prices, and durations.
* **Appointment Booking:** Real-time slot availability and instant booking.
* **History & Profile:** Track past and upcoming appointments seamlessly.

## Installation
1. Clone the repository.
2. Run `flutter pub get`.
3. Configure the environment variables by copying `.env.dev` to `.env` or running with `--dart-define=ENV=dev`.
4. Run `flutter run`.

## Tech Stack
* **Frontend:** Flutter (Dart), Provider state management.
* **Backend:** Laravel 11, MySQL, Sanctum API.
* **Design:** Material 3, custom Indigo/Blue typography.
